# Security policy

Please do not publish security vulnerabilities, passwords, TVTeam credentials, payment details, wallet recovery phrases or private account links in a GitHub issue.

Report security and privacy matters privately to **kontakt@keisplay.pl**. Include the KeisPlay version and only the minimum information needed to explain the problem.

The KeisPlay application source code is maintained in a private repository. This public repository contains releases, issue forms and project-level information only.
